# DreamCareer 🎯

**Live:** https://dreamcareer-theta.vercel.app

---

## Why I built this

I wanted to build something real. Not a university assignment, not a tutorial — something that had a real chance of being useful to people and maybe even making some money.

The idea was simple: most people feel lost about their career at some point. I wanted to build a quiz that helped them figure out which careers actually match the life they want, based on real salary data.

Did it become a huge success? Not exactly. But that was never really the point.

## What I actually learned

Before this project, I knew basic HTML. That was it.

Building DreamCareer taught me JavaScript for real — not exercises, but actual problems I had to solve. I learned how to structure a project across multiple files, how to manipulate the DOM, how to build a scoring algorithm from scratch, and how to integrate a payment system. I learned how to deploy a live website that anyone in the world can access.

Those are things I'll carry into every project I build from here.

## What it does

- 15-question quiz that scores the user across 4 career profiles
- Matching algorithm that identifies the dominant profile
- Personalized result with 3 matched careers, real US salary data by level, and a concrete path to get there
- Paywall that unlocks the full report after payment

## Tech stack

HTML · CSS · JavaScript · Vercel · Gumroad
